Сервис хранит синтетические входящие события и состояния сессий в SQLite. Миграция версионируется. Уникальный ключ подавляет дубли, а общая транзакция связывает переход состояния с отметкой обработки. Точка запуска описана в README. CI запускает проверку синтаксиса, тесты и CLI replay.

На переносимом Python 3.12.10 прошли три теста. Проверены конкурирующие записи и обработчики, повторное открытие базы, сохранение ручного управления и отклонение неверного события. CLI replay обработал два события. Локальный HTTP вернул 200 для `/health` и `/ready`, 404 для неизвестного пути.

SQLite здесь обслуживает синтетический контур. Входящие события целевого портала, исходящие действия и CRM входят в E3. CI проверяется отдельно после публикации.
