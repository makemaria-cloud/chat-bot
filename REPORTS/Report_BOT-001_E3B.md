# BOT-001 E3B. Исходящие действия, передача и CRM

- **Дата** — 20 ноября 2026 года
- **Задание** — [E2A и E3](../TASKS/BOT-001_E2A_E3.md)
- **Ветка** — `main`
- **Предыдущий коммит** — `cb49c0b`, отправлен в GitHub

Миграция 004 добавляет outbox, версию обработанного состояния и подтверждённые привязки CRM. Действия планируются атомарно. Отправитель повторно сверяет версию, сессию, владение и управляющие события, а сетевой вызов выполняет вне транзакции. Успешный приём сообщения или передачи API требует отдельного подтверждения. Таймаут либо прерванная попытка попадают в очередь сверки без повторной отправки. Для CRM используются подтверждённая привязка или отдельная политика создания с защитой от дублей.

На Python 3.12.10 прошли 32 теста `unittest`. Проверены полный откат на сбое вставки outbox, остановка после управляющих событий, переключение сессии, конкурирующая отправка, доступность записи SQLite во время вызова, восстановление попыток, ответы 403/429/503 и таймаут, передача, CRM и отсутствие внешних мутаций по умолчанию. На чистой временной SQLite результаты replay составили `2/2` и `0/0`. Вызовы `worker --once` и `outbox-review` завершились успешно. Для переносимого Python корень добавлен в `sys.path`; CI использует обычный Python.

Локальная контрактная реализация проверена. Реальные установка, поля, очереди, права, правила хранилища и внешняя проверка актуального владения остаются открытыми. Обычный CLI работает без внешних действий. Граница гонки после последней проверки и порядок отключения описаны в [контракте](../docs/bitrix-contract.md).
