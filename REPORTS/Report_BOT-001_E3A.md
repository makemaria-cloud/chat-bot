# BOT-001 E3A. Входной адаптер и устойчивый контекст

- **Дата** — 20 ноября 2026 года
- **Задание** — [E2A и E3](../TASKS/BOT-001_E2A_E3.md)
- **Ветка** — `main`
- **Предыдущий коммит** — `e09d032`, отправлен в GitHub

Webhook Bot API 2.0 проверяет токен, портал, бота и разрешённую пару линии и коннектора. Для подтверждения роли, исходной сессии и текущего владельца используется [контракт привязок](../docs/bitrix-contract.md). В локальном запуске источник — синтетический файл. Без него запросы отклоняются. Миграция 003 добавляет минимальный контекст, актуальную сессию чата и индекс ожидающих событий.

Входная транзакция выполняется до HTTP 200. Отдельный воркер продолжает с того же файла после рестарта. Исходная сессия сообщения сохраняется отдельно от текущей сессии чата. Привязка с меньшей ревизией не перезаписывает текущую. Токен, полный payload и текст оператора не сохраняются.

На Python 3.12.10 прошли 16 тестов `unittest`. Проверены миграция со схемы E2, отказ при чужом токене и маршруте, неверные типы и лимиты, фильтрация системных и собственных сообщений, конкурентный повтор, конфликт, сохранение текста после перезапуска, приоритет актуальной сессии и смена владельца до обработки.

Подключение портала открыто. Требуется проверить способ установки, права, поля обратного вызова, источники членства сообщения в сессии и состояния владения, правила хранения и удаление данных. Исходящие действия относятся к E3B.
