# Чат-бот для Avito и Bitrix24

Проект чат-бота ДАЙЯ групп для обработки обращений по аренде и продаже опалубки, бытовок и строительных лесов.

## Текущий этап

Идёт исследование требований и существующих переписок. Код пока не разрабатывался.

Обезличенные результаты анализа, предлагаемая логика обработки чатов и вопросы для согласования собраны в [документе исследования](docs/research.md).

## Принцип работы

Цель бота — не просто получить телефон, а установить полезный контакт, вызвать доверие, квалифицировать задачу и передать менеджеру контекст, повышающий вероятность первой и повторных сделок.

Предполагаемый контур интеграции:

```text
Avito webhook -> обработка и квалификация -> Bitrix24 Open Lines -> CRM -> менеджер
```

## Безопасность данных

Репозиторий не должен содержать дампы БД, реальные переписки, имена, телефоны, адреса объектов, внешние идентификаторы клиентов, токены и другие персональные или секретные данные.
